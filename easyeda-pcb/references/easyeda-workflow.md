# EasyEDA editor workflow

## Work without the editor

Use the [project playbook](project-playbook.md) and [reference library](hardware-rag.md) to settle requirements, build a power tree, and check component choices. For schematic work, create or review the circuit connections in an editor-independent form. Record each part's reference designator, exact part and package, pin number and name, intended net, and deliberate unconnected pins. Include circuit values and the source for critical connections. Review the resulting connectivity, polarity, pin numbering and interfaces against the datasheets and stated requirements. A block diagram can describe the architecture alongside the pin-to-net table.

Use the [PCB rulebook](design-rules.md) and [layout guidance](stackup-and-layout.md) to prepare a layer map, net rules, mechanical constraints, and placement and routing priorities. Review supplied schematic PDFs, netlists, or manufacturing exports within the evidence they provide. Run the [Gerber archive inspector](../scripts/inspect_gerber_zip.py) on an available ZIP for filename inventory. Record the project revision and remaining work. Confirm native import, schematic-to-PCB connectivity, editor rule checks, final copper and exports once you have the corresponding editor session or revision-matched evidence.

## Match the project and execution method

Identify Pro vs Standard from the editor or source export. Confirm the active project and PCB, especially for multi-board projects. Work in a named backup or local copy before a migration, bulk library update, raw-source edit, or layer-count reduction. Existing projects should stay in their edition unless the user requests migration or the task genuinely needs it. For a migration, compare part and net counts, pin-to-pad mappings, outline, rule assignments, pours, plane partitions, and ratlines after import. [Pro migration notes](sources/easyeda-notes.md#pro-migration-and-schematic-sync)

Use an available editor integration for authorized edits. For Pro desktop, follow the official automation guide for the installed version. Locate the CLI and check `easyeda-pro doctor` for a connected, compatible bridge. Discover commands and API signatures with the installed CLI and confirm the session's project path and board before writing. Check command results and verify that the intended board objects, connectivity, and export files reflect the edits. Run the relevant native checks. If generating source directly, use the documented format for that version and editor-produced templates and library records. Open and verify the resulting project in EasyEDA. For browser and Standard projects, use the documented GUI workflow where available. [Local Pro CLI guide](sources/vendor/easyeda-client-cli/cli-for-ai.md), [local design format reference](sources/vendor/easyeda-client-cli/easyeda-format.md)

## EasyEDA Pro

1. In the schematic, use **Design → Update/Convert Schematic to PCB** for the initial transfer. For an existing board, use **Design → Import Changes from Schematic** from the PCB and inspect the change list for renamed or deleted nets, footprint replacements, and new or overwritten placements. Check that the active PCB and schematic are the intended pair. [Pro schematic sync notes](sources/easyeda-notes.md#pro-migration-and-schematic-sync)
2. Open **Tools → Layer Manager**. Set the copper count and choose signal layers with pours or dedicated internal plane layers as the design requires. In a dedicated plane layer, verify each region's actual net and its connection rule. Pro displays dedicated internal planes using a negative convention and exports positive artwork in current versions. Judge fabricated copper from the export in a CAM viewer. [Pro layer notes](sources/easyeda-notes.md#pro-layer-manager)
3. Open **Design → Design Rule** to build rules. Assign them to actual nets or net classes, and check any region-specific overrides. Use the PCB Nets panel or the version's corresponding managers to define differential pairs and length groups. Confirm pair polarity and membership before routing. Report which constraints are enforced by the configured rules and which were checked separately. [Pro rules and net notes](sources/easyeda-notes.md#pro-rules-and-nets)
4. Rebuild all copper with **Shift+B**, including internal planes. Run **Design → Check DRC** and inspect ratlines with filters cleared. The export settings can also check DRC and net connections. Save the board and retain the final results or screenshots for the frozen revision. [Pro copper and DRC notes](sources/easyeda-notes.md#pro-copper-and-drc)
5. Use **Export → PCB Fabrication Files (Gerber)**. For assembly, use **Export → Bill of Materials (BOM)** and **Export → Pick and Place File**. Use project-specific settings for required layers and assembly variants. [Pro export notes](sources/easyeda-notes.md#pro-fabrication-and-assembly-export)

## EasyEDA Standard

1. Convert the schematic for a new board. Use **Design → Update PCB** in the schematic or **Design → Import Changes** in the existing PCB to synchronize later edits. Review changes to components and nets before applying them. [Standard schematic sync notes](sources/easyeda-notes.md#standard-schematic-sync-and-layers)
2. Open **Tools → Layer Manager** for the active PCB. Set the copper count and inspect every inner layer's type and assigned net. Changing display visibility leaves layer objects eligible for export. Inspect contents before reducing the layer count. Standard exports distinguish signal and dedicated inner-plane layers in documented Gerber filenames. [Standard layer notes](sources/easyeda-notes.md#standard-schematic-sync-and-layers)
3. Open **Tools → Design Rule** to set dimensions and apply rules to the relevant nets. Check the canvas units and the copper-area and board-outline checks. For paired routing, use matching `_P`/`_N` or `+`/`-` net names and set the pair rule before **Route → Differential Pair Routing**. Use **Route → Track Length Tuning** where needed. Standard's pair router allows DRC violations during routing, so inspect neck-downs, fanouts and transitions, measure width, gap and skew, and run the full check afterward. [Standard rules and routing notes](sources/easyeda-notes.md#standard-rules-and-routing)
4. Rebuild pours with **Shift+B**, then run **Design → Check DRC** and inspect Design Manager for unresolved ratlines. Verify any project constraints outside the configured checks with explicit measurements or external analysis. [Standard DRC notes](sources/easyeda-notes.md#standard-rules-and-routing)
5. Use **Fabrication → PCB Fabrication File (Gerber)** or its equivalent in **File**. For assembly, use the BOM export and **Fabrication → Pick and Place File** where available. Confirm coordinates and units in the resulting file. [Standard fabrication export notes](sources/easyeda-notes.md#standard-fabrication-export), [BOM and placement notes](sources/jlcpcb-notes.md#bom-and-placement)
